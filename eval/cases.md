# 评估用例

每个阶段结束时追加本阶段的用例。用例描述"输入 → 期望的工具行为 + 期望的回答特征"，
人工跑 chat.py 对照；结果记在最后一列。失败的用例是下一次改提示词 / 代码的依据。

判定关注三件事：工具选择对不对、工具结果有没有被如实使用、回答有没有编造。
